## ⚙️ Getting Started & Local Development

To run this portfolio locally on your machine:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Salmanyuris/Salmanyuris-porto-beta.git
   cd Salmanyuris-porto-beta
   ```

2. **Run Locally**
   - Open `index.html` directly in any web browser, OR
   - Use VS Code **Live Server** extension for real-time preview.
